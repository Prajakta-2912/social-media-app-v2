# 🚀 Social Media Web App (Full Stack Project)

A fully functional full-stack social media web application built using **HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB**.  
This project includes authentication, posts, likes, comments, and follow/unfollow system with real backend integration.

## ⚙️ How It Works

1. User registers or logs in
2. JWT token is generated and stored in localStorage
3. Frontend sends API requests to backend
4. Backend processes requests using Express routes
5. MongoDB stores users, posts, comments, and follow data
6. Frontend dynamically updates UI using fetched data

---

## 🔗 API Endpoints

### Auth Routes:
- POST /api/auth/register
- POST /api/auth/login

### Post Routes:
- GET /api/posts
- POST /api/posts
- PUT /api/posts/like/:id
- POST /api/posts/comment/:id

### User Routes:
- Follow / Unfollow system APIs
